# ATELIER — Parfyumeriya do‘koni demo
HTML, CSS va JavaScript asosida yaratilgan moslashuvchan portfolio sayti.

## Fayllar
- `index.html` — sahifa tuzilishi
- `style.css` — dizayn va mobil moslashuv
- `script.js` — mobil menyu va mahsulot filtrlari

## Ishga tushirish
`index.html` faylini brauzerda oching.

## GitHub Pages
4 faylni repository asosiy papkasiga yuklang. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Mijozga topshirishdan oldin
Demo nomi, telefon, manzil, Telegram havolasi, mahsulotlar, narxlar va rasmlarni do‘konning haqiqiy ma’lumotlari bilan almashtiring. Hozirgi mahsulotlar va narxlar namunaviy.
